**Strona online:** https://adasieqk.github.io/alfik-matematyczny-2026/

| Plik | Zawartość |

## Uruchomienie lokalnie

To statyczne pliki HTML – wystarczy otworzyć `index.html` w przeglądarce. Wzory renderuje KaTeX ładowany z CDN (jsDelivr), więc potrzebny jest internet.

## Publikacja na GitHub Pages

1. Wypchnij repo na GitHuba (`git push`).
2. W repo: **Settings → Pages**.
3. **Source:** *Deploy from a branch*, **Branch:** `main`, folder `/ (root)` → **Save**.
4. Po minucie–dwóch strona jest pod adresem: https://adasieqk.github.io/alfik-matematyczny-2026/

## Druk / PDF

Na każdej stronie przycisk **„Rozwiń wszystko i zapisz jako PDF / Drukuj”** otwiera wszystkie rozwiązania i uruchamia drukowanie (w oknie drukowania wybierz „Zapisz jako PDF”). Układ jest przygotowany pod A4, a zadania nie rozrywają się między stronami.
